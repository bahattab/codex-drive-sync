# codex-drive-sync

برنامج لمزامنة ملفات المشاريع عبر لقطات مشفرة، مع كشف التعارضات ونسخ احتياطية محلية واستعادة. يتضمن موفرًا محليًا للاختبار وموفر Google Drive API، وواجهة أوامر وخدمة دورية وإضافة مهارة وMCP للقراءة.

**هذا الإصدار لا يحقق بعد الاستمرارية الكاملة بين جهازين داخل Codex.** نقل المحادثات الأصلية وظهورها ومتابعتها في واجهة Codex غير مثبت، ولذلك الاستيراد الأصلي معطل. الأرشفة وحفظ السياق قدرات مستقلة. نجح تفويض Google الحقيقي والنقل المشفر عبر API بين بيئتين محليتين مؤقتتين؛ اختبار الجهاز الثاني الحقيقي لم يُنفذ بعد.

ابدأ من [دليل التثبيت](docs/INSTALL_AR.md)، ثم [إعداد Google](docs/GOOGLE_AR.md)، و[الاستعادة والتعارضات](docs/RECOVERY_AR.md). راجع [التوافق](COMPATIBILITY.md) و[الاختبارات](TEST_RESULTS.md) و[اختبار الجهاز الثاني](docs/SECOND_DEVICE_AR.md) قبل استعمال بيانات فعلية.

## تشغيل التطوير

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock
.\.venv\Scripts\python.exe -m pip install --no-deps -e .
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\codex-drive-sync.exe doctor
```

المصدر لا يتضمن بيانات مستخدم أو مفاتيح أو ملفات تفويض. فحص الأسرار مساعد ولا يضمن اكتشاف كل محتوى حساس. لا تستخدم هذا البرنامج لنقل `.codex` كاملًا أو قواعد SQLite أو `.git` الحية.

## حدود الإصدار

- 32 MiB للملف، و256 MiB لمجموعة المشاريع، و10,000 ملف. الملفات الثنائية والأسماء العربية مدعومة ضمن قيود Windows.
- لا روابط رمزية أو junctions، ولا أسماء Windows المحجوزة أو تعارض اختلاف حالة الأحرف. المسارات المحلية لا تدخل البيانات الوصفية السحابية.
- يظل اختيار المشاريع وتفعيل المهارات والإضافات والإعدادات يدويًا. مخزون الإضافات لا يعني تثبيتها أو ربط حساباتها.
- لا دمج نصي تلقائي للملف المتعارض. تبقى النسخ في اللقطات المشفرة ويختار المستخدم النسخة صراحة.
- لا قفل موزع، ولا ضمان نقل العمليات أو الأدوات الجارية. افحص التعارضات عند كل تسليم.
- الموفر المحلي لا يثبت سلوك Google Drive for desktop. يمكن اختيار مجلد ينقله ذلك التطبيق إذا كان مثبتًا، لكن سلامة ونهاية وصوله بين الجهازين تحتاج اختبارًا منفصلًا.
- لا جمع قمامة آلي: اللقطات والحمولات وعلامات حذف الملفات ضمن اللقطات والنسخ المحلية محفوظة دون حد زمني. توقف الخدمة عند بلوغ حد كتالوج اللقطات بدل إسقاط تاريخ جهاز طويل الغياب. راجع المساحة دوريًا؛ لا تحذف أسلاف اللقطات يدويًا.
- تدوير المفتاح غير مدعوم في هذا الإصدار. فقد المفتاح ونسخة الاسترداد يعني فقد إمكانية فك الحمولة السحابية.

## حالات القدرة

| القدرة | الحالة |
|---|---|
| محرك ملفات مشفر بموفر محلي | راجع نتائج الاختبارات الحالية |
| OAuth وموفر Drive API | منفذ؛ اختبار حي لمحتوى اصطناعي PASS |
| مهارات مختارة وإعدادات مسموحة ومخزون تعريفات | تصدير ونقل ملفات؛ التفعيل على الجهاز الثاني NOT RUN |
| أرشفة JSONL والبحث بمواقع السجلات | منفذ؛ لا استئناف أصلي |
| نقل محادثة داخل Codex واستمرار الأدوات والمرفقات | BLOCKED |
| تسليم حالة Codex متماسكة بين جهازين | BLOCKED؛ اختبار حقيقي NOT RUN |

المراجع: [تعبئة إضافات OpenAI](https://developers.openai.com/plugins/build/plugins)، [OAuth لسطح المكتب](https://developers.google.com/identity/protocols/oauth2/native-app)، [بيانات تطبيق Drive](https://developers.google.com/workspace/drive/api/guides/appdata). تفاصيل الأدلة والإصدارات في تقرير التوافق.
