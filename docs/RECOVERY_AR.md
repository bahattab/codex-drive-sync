# التعارض والتسليم والاستعادة

التسليم الافتراضي للملفات: أوقف تحرير المشروع، راجع الجرد، ثم `handoff prepare`؛ تحقق من snapshot_id، وعلى الجهاز الآخر نفذ `handoff receive --snapshot ID --dry-run` ثم الاستقبال. يجري فحص الحمولة قبل تفعيل الملفات. لا ينقل هذا الإجراء عمليات Codex أو قاعدة المحادثات أو ارتباطات المرفقات، ولا يعطي ملكية حصرية لجهاز.

إذا عمل الجهازان دون اتصال، تحفظ اللقطات كسلالات مستقلة ثم تقارن بالمشترك السابق. التعديلات على ملفات مختلفة تجمع؛ تعديل الملف نفسه أو الحذف مقابل التعديل يظهر كصراع، دون اختيار الفائز اعتمادًا على الساعة. أول اقتران يحفظ البيانات المحلية الإضافية ولا ينشر حذفًا متبادلًا تلقائيًا.

```powershell
codex-drive-sync conflicts list
codex-drive-sync conflicts resolve --id CONFLICT_ID --choice local
codex-drive-sync conflicts resolve --id CONFLICT_ID --choice 0
```

الفهرس يبدأ من صفر بحسب variants في القائمة؛ يمكن استعمال البصمة نفسها أو `delete` لاختيار الحذف صراحة. القرار يسجل في لقطة جديدة؛ راجع النسخة المختارة ثم زامن الجهازين. النسخ البديلة باقية في السجل المشفر. لا تدمج ملفات أدوات التنفيذ أو محادثات مختلفة تلقائيًا.

`snapshots list` يعرض الصور السابقة. قبل الاستعادة استخدم `restore ID --dry-run`، ثم `restore ID`. الاستعادة الصريحة قد تحذف الملفات المتتبعة غير الموجودة في الصورة، لكنها تنشئ نسخًا محلية قبل التغيير. احفظ نسخة مستقلة للمشروع خارج حساب Google وموفر النقل أيضًا.

سجل معاملات محلي يعيد الملفات عند فشل التفعيل. إذا تغير ملف بعد الانقطاع بصورة مستقلة، يجب ألا يحذف تعديلك أثناء التعافي؛ تبقى المعاملة والنسخ الاحتياطية ويُطلب حل الحالة بعد حفظ النسختين. لا تحذف journal يدويًا ولا تكرر المحاولة في وجود تحرير مستمر. توقف عن تحرير الملفات أثناء activation؛ البرنامج لا يقفل المحرر ولا يقدم لقطة نظام ملفات ذرية لمشروع يجري تعديله خارجيًا.

أرشفة محادثة تختارها: `archive --source conversation.jsonl --output C:\Private\archive1`؛ تحفظ البايتات وترتيب السجلات ولا تعدل الأصل. `archive-search --archive ... --query ...` يعرض مواضع سجلات المطابقة. `context.md` يتضمن السجلات مرتبة داخل كتلة مرجعية مع بيان عدم تنفيذ تعليماتها؛ ليس تلخيصًا مولدًا ولا استيرادًا أصليًا. راجعه قبل إرفاقه، فقد يحتوي معلومات حساسة. اختر المرفقات يدويًا؛ لا يخمن البرنامج ارتباطاتها الداخلية.

كل اللقطات وعلامات الحذف ضمن manifests والنسخ المحلية تحتفظ بها النسخة الحالية دون تنظيف آلي. عند امتلاء الحدود توقف وتحقق، ولا تحذف أسلاف DAG لأن جهازًا غير متصل قد يحتاجها. لا توجد أداة جمع قمامة أو rollback لحالة Codex الأصلية لأنها لا تُستورد.
